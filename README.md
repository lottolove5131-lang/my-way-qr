# 내 방식 QR — 키오스크 접근성 프로필 패스

2026 AI 라이프 솔루션 챌린지 출품 시제품입니다. 「AI 라이프 아이디어 챌린지」 후보작 「내 방식 QR: 범용 접근성 프로필 패스」를 실제로 동작하는 웹 서비스로 구현했습니다.

- 시연: https://lottolove5131-lang.github.io/my-way-qr/
- 설치 없이 크롬에서 바로 실행됩니다. 음성 인식은 크롬에서 동작하며, 안 될 때는 글로 입력할 수 있습니다.

## 무엇을 하나

1. 사용자가 불편한 점을 자기 말로 적거나 말하면, 휴대폰 브라우저 안의 AI 모델이 필요한 화면 설정 8가지(큰 글씨·고대비·쉬운 말·음성 안내·말로 주문·화면 낮게·시간 제한 없음·단계 줄이기)를 추천하고, 손 사용이 어렵다고 보이면 터치 보정도 함께 켭니다.
2. AI 추천은 설정에 미리 켜 두고, 사용자가 끄고 켜며 확인한 뒤 「이대로 QR 만들기」를 눌러야 설정과 글자 배율만 QR(`MWQ1.<설정 9비트>.<배율>`, 10자 안팎)로 저장합니다. 이름·연락처·장애 여부는 담지 않습니다.
3. 키오스크(카페 주문·병원 접수 두 종류)가 QR을 읽으면 화면이 그 사람에게 맞춰 바뀌고, 결제·접수 전에 선택 내용을 다시 확인하며, 끝나면 설정을 지워 다음 사람은 원래 화면으로 시작합니다.
4. 키오스크가 지원하지 않는 설정은 숨기지 않고 「미지원」으로 보여 주고 직원 부르기 단추를 크게 띄웁니다. 운영자 리포트는 어떤 설정이 몇 번 쓰였는지만 셉니다.

## AI 구성

| 구성 | 실행 위치 | 방법 |
|---|---|---|
| 내 말 → 설정 추천 | 브라우저 | 글자 1~3그램 TF-IDF + 라벨별 로지스틱 회귀(다중 라벨). 학습은 scikit-learn, 추론은 JavaScript로 같은 계산을 재현(오차 0.00005 이하) |
| 메뉴 쉬운 말·그림·부르는 말 | 메뉴 등록 때 1회 | 생성형 AI(Gemini 2.5 Flash)가 생성하고 사람이 검수 |
| 말로 한 주문 이해 | 키오스크 | 브라우저 음성 인식 → 자모 단위 편집거리로 별칭 사전과 비교, 비슷한 후보가 둘이면 되묻기 |

## 데이터와 검증

- `data/profile_train.json`: 학습 문장(Gemini 2.5 Flash 생성)
- `data/profile_test.json`, `data/order_final.json`: 시험 문장(학습 데이터와 다른 모델인 Gemma 4가 생성)
- `data/final_eval.json`: 최종 채점 결과(화면·보고서 수치). `profile_model.json`의 `eval`은 문장을 나누지 않고 한 번에 추론한 참고값이며, 앱은 문장을 나눠 읽는 방식(final_eval의 profile 값)을 씁니다.
- 실제 사용자 시험은 아직 하지 않았습니다. 수치는 합성 문장 기준입니다.
